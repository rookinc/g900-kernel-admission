\begin{abstract}
This note gives a finite kernel-admission theorem for an explicit 900-vertex graph candidate generated from a 15-slot graph, a 60-state fiber graph, and a signed half-flip carrier law. The object is not identified by visual rendering, census lookup, or physical interpretation. It is admitted by finite data and independently checkable certificates.

The certified claim set contains 6 direct kernel consequences and 7 certificate-backed graph claims. The generated edge set has 3600 edges and matches the recorded canonical edge set exactly. The graph is connected, has diameter 8, radius 6, and separates from the untwisted product baseline by exact metric invariants. A sibling signing is shown not to be switching-equivalent to the canonical signing, and the corresponding sibling graph is separated by exact graph invariants. The theorem is bounded: it does not assert uniqueness, census identity, physical interpretation, or invalidity of the sibling candidate.

A companion overlay audit records a local WXYZTI reciprocal pair grammar: within a realized row-pair candidate universe of 48 pairings, a reciprocal answer-pair selector accepts exactly the 12 realized answer-pairs. This overlay result is explicitly separated from the kernel-admission theorem and does not close Gap A.
\end{abstract}
