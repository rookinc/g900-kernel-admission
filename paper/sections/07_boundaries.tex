\section{Boundaries of the result}

The theorem is intentionally bounded. It proves the listed claims for the explicit finite kernel and certificate set. It does not assert the following.

\begin{enumerate}[leftmargin=2em]
\item It does not assert uniqueness among all possible signed carrier systems.
\item It does not assert identity with any graph census entry.
\item It does not assert a physical interpretation.
\item It does not assert that the sibling graph is invalid.
\item It does not depend on visual rendering or interactive display.
\item It does not claim that the WXYZTI reciprocal pair grammar closes Gap A.
\item It does not claim that the WXYZTI row-pair candidate universe has been generated natively from \(G_{60}\) or \(G_{15}\).
\end{enumerate}

These exclusions are part of the theorem discipline. The result is not weakened by them; it is made accountable by them.
