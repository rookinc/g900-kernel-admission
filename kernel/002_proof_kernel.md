# Proof kernel

## Definition

The G900 proof kernel is

    P_900 = (K_900, C)

where:

- K_900 is the construction kernel.
- C is the finite certificate bundle required for admission.

## Certificate bundle C

The certificate bundle should include finite witnesses for:

1. connectedness of X_sigma,
2. diameter 8,
3. radius 6,
4. exact equality with the recorded canonical candidate edge set,
5. separation from the untwisted product baseline,
6. sibling non-coboundary / non-switching-equivalence,
7. sibling full-graph separation by exact invariants.

## Direct proof versus certificate

Direct finite proof covers:

- vertex count,
- edge count,
- internal edge count,
- external edge count,
- degree split,
- 8-regularity.

Certificates cover:

- connectedness,
- diameter,
- radius,
- edge-set equality,
- distance distribution,
- sibling separation.

## Admission principle

A bounded G900 theorem is admitted only when the construction kernel and proof kernel allow the stated claims to be checked without relying on renderings, visual ring geometry, or informal project memory.
